## 3. HubRelay (ตัวกลางอ่านไฟล์ส่วนตัว)

- โปรเจกต์ Apps Script **“HubRelay”** ในบัญชี rawee.jum@mahidol.ac.th (สร้างใหม่ 1 โปรเจกต์ ไม่มีโปรเจกต์เดิมซ้ำ) · Web app: ดำเนินการในฐานะเจ้าของ · ผู้มีสิทธิ์เข้าถึง “ทุกคน” (มหาวิทยาลัยอนุญาตตัวเลือกนี้) · เวอร์ชัน 2 (URL เดิมตั้งแต่เวอร์ชัน 1)
- สิทธิ์ (appsscript.json): `spreadsheets.readonly`, `drive.readonly`, `script.external_request` — อ่านอย่างเดียว · ไม่มี `@OnlyCurrentDoc`
- อ่านได้เฉพาะ 2 แท็บ/คอลัมน์ที่กำหนดในโค้ด (ทะเบียนรถส่งเป็น “มี/ไม่มี”) และภาพใต้โฟลเดอร์ SecurityGuardReports · ทุกคำขอต้องมีค่าลับ (Script Properties `RELAY_SECRET` ↔ D1) · ไม่ส่ง OAuth token ออก · ไม่เปลี่ยนการแชร์
- Script Properties: `RELAY_SECRET` (ค่าลับ), `RELAY_EXEC_URL` (URL /exec — ไม่ใช่ความลับ)
- ลงทะเบียน 2 ขั้น: `/api/relay/enroll` จอง token แบบ atomic (`DELETE … RETURNING`) → “รอตรวจ” · `/api/relay/confirm` บริการเรียก /exec จริง (รุ่นโค้ด + 2 ตาราง + ภาพตัวอย่าง) ผ่านครบจึงเปิดใช้ · ตัวกลางเดิมใช้งานต่อจนตัวใหม่ผ่าน · setup ซ้ำ = ตรวจอย่างเดียว ไม่ใช้ token ซ้ำ
- ผล setup จริง (Execution log 23:05): อ่าน Registrations_Motorcycle 480 แถว · RuenThai_Survey 370 แถว · โฟลเดอร์ภาพ SecurityGuardReports · ระบบเรียกสคริปต์: ok (r11) · ตาราง ok:480 / ok:370 · ภาพ ok · “ติดตั้งสำเร็จและผ่านการตรวจจากระบบแล้ว”
- token ลงทะเบียน: สร้างภายในหน้า Apps Script (ไม่ผ่านแชท) และหมุนใหม่ 1 ครั้งก่อนใช้ เพราะเครื่องมืออ่านหน้าจออ่านโค้ดที่มี token ฉบับแรกเข้ามาในบันทึกการทำงานของ Claude (ไม่ได้พิมพ์ในแชท) — token ฉบับนั้นถูกยกเลิกก่อนใช้งาน · ฉบับที่ใช้ถูกใช้แล้ว (ลบจาก D1) และลบออกจากโค้ดในโปรเจกต์แล้ว · ไฟล์ `HubRelay_for_owner.gs` ที่ส่งก่อนหน้า **ใช้ไม่ได้แล้ว**

แบบฟอร์มภายนอก (ลิงก์เดิม ทำงานตามระบบต้นทาง): รถเข้า/หมวกนิรภัย · ตรวจสภาพยานพาหนะ · ขอดูกล้อง CCTV · ตรวจ/เติมสารถังดับเพลิง · ความพึงพอใจ รปภ.เอกชนส่วนกลาง/ส่วนงาน 6 สัญญาจ้าง (URL เดิม) — ต้องทำรอบพัฒนา “การเขียนข้อมูล” แยกต่างหาก (HubRelay เป็นแบบอ่านอย่างเดียว ไม่ใช้เขียน)

## 8. สิทธิ์ผู้ดูแล (ADMIN_CODES) — ยังไม่ได้ตั้ง

ตรวจแล้ว: Pages env ไม่มี `ADMIN_CODES` → ทุกคนเป็นผู้ใช้ทั่วไป อ่านรายชื่อเวรได้ แก้ไม่ได้ (ไม่มีใครได้สิทธิ์ผู้ดูแลอัตโนมัติ ไม่มีรหัสฝังในโค้ด)
ตั้งเอง (รหัสไม่ผ่านแชท):
1. https://dash.cloudflare.com → Workers & Pages → **mu-traffic-hub** → Settings → **Variables and Secrets** → **Add**
2. Type: **Secret** · Variable name: `ADMIN_CODES` · Value: รหัสพนักงานผู้ดูแล คั่นด้วยจุลภาค (เช่น `รหัส1,รหัส2`) · Environment: Production → Save
3. แจ้ง Claude ว่า “ตั้งแล้ว” → Claude Deploy ใหม่ (ค่าใหม่มีผลกับ Deployment ถัดไป) แล้วให้ผู้ดูแล Login ตรวจหน้า ตั้งค่า → รายชื่อประจำผลัด ต้องเห็นปุ่มแก้ไข
ทดสอบแล้ว (Mock): ผู้ใช้ทั่วไปอ่านได้แก้ไม่ได้ · ผู้ดูแลแก้/ย้าย/ปิดได้ · ถอดสิทธิ์มีผลทันที · ป้องกันแก้พร้อมกัน (รุ่นข้อมูล) · CSRF · ไม่เขียน D1 จริง

## 9. คู่มือดูแล HubRelay

**อัปเดตโค้ดรุ่นใหม่** (URL เดิม ไม่ต้องลงทะเบียนใหม่): เปิดโปรเจกต์ HubRelay (บัญชี rawee.jum) → วางโค้ด `apps-script/HubRelay.gs` ทับทั้งไฟล์ (ค่า `__ENROLL_TOKEN__` คงไว้) → บันทึก → การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชัน: **เวอร์ชันใหม่** → การทำให้ใช้งานได้ → เลือก `checkInstall` → เรียกใช้ → log ต้องขึ้น “ติดตั้งสำเร็จ … (ใช้งานอยู่แล้ว)” · ถ้า `RELAY_VERSION` เปลี่ยน ต้อง Deploy Worker รุ่นที่ตรงกันด้วย

**ตรวจ/กู้คืน**: รัน `checkInstall` หรือดูหน้า ตั้งค่า → HubRelay · log บอกสาเหตุและวิธีแก้ (`relay-login-required` → ตั้ง “ทุกคน” · `outdated` → New version · URL /dev → ใส่ `RELAY_EXEC_URL`) · ค่าลับหาย/ไม่ตรง: ผู้ดูแลออก token ใหม่ (เขียน hash ลง D1 `meta.relay_enroll` — ให้ Claude ทำได้) → ใส่ใน Script Properties `ENROLL_TOKEN` → ลบ `RELAY_SECRET` → รัน `setup` (ตัวเดิมยังใช้งานจนตัวใหม่ผ่านการตรวจ ไม่ต้องสร้างโปรเจกต์ใหม่)

**ปิด/หมุนค่าลับ (ไม่กระทบระบบเดิม)**: ปิดชั่วคราว → จัดการการทำให้ใช้งานได้ → เก็บ (Archive) → หน้าเว็บแสดงสาเหตุ ข้อมูลส่วนตัว/ภาพ GPS หยุดแสดง แหล่งอื่นและ Login ใช้ได้ตามเดิม · ถอนถาวร → ลบแถว `relay_url`, `relay_secret` ใน D1 และเพิ่มเลข `img_cache_ver` (ล้างภาพที่แคช) · หมุนค่าลับ → ทำตาม “ค่าลับหาย” ด้านบน
