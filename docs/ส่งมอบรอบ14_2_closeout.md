   - เก็บเฉพาะข้อผิดพลาด: `route-error` (HTTP ≥500), `stats-part-error`, `lkg-read-error`, `lkg-write-error`, `stats-cache-write-error`, `auth-d1-error`
   - ช่อง (allowlist): เวลา UTC (ms), ref, รุ่นบริการ, เหตุการณ์, route (เฉพาะในรายการ ไม่มี query), scope, part, stage, HTTP, code, ชนิด error, **ชนิดสาเหตุเดิมก่อนห่อเป็น Err**, ข้อความ ≤160 ตัวอักษร (ตัด URL/อีเมล/ตัวเลขยาว/รหัสยาว/key=value/ข้อความในเครื่องหมายคำพูด และอักษรนอก ASCII)
   - ไม่เก็บ: cookie, token, secret, รหัสพนักงาน, IP, query เต็ม, เนื้อหาคำขอ/คำถาม AI, แถวจาก Sheet, ชื่อ/อีเมล/เบอร์/ทะเบียน/ภาพ, stack
   - ทุกเหตุการณ์ของคำขอเดียวผูกด้วย ref เดียวกัน (เก็บใน deps ของคำขอนั้น ไม่ใช่ตัวแปร global)
   - กันซ้ำในคำขอเดียว · ไม่เกิน 12 รายการต่อคำขอ · **เพดาน 1,000 รายการล่าสุด** — ล้างของเก่าเฉพาะตอนเขียนรายการใหม่ (ไม่มี TTL อัตโนมัติ)
   - best effort: เขียนไม่ได้ → แจ้ง `diag-write-error` ใน console ครั้งเดียว (ไม่วนเรียกตัวเอง) · คำตอบเดิมไม่เปลี่ยน · ตรวจสิทธิ์ไม่ได้ยัง 503 ไม่มีข้อมูล
2. **ref = รหัส ray ของ Cloudflare** (ตัดรหัสศูนย์ท้าย เช่น `-BKK`) ตรงกันทั้งในคำตอบ หน้าเว็บ และ `diag_log`
3. **หน้าเว็บ**
   - ใช้ ref จาก JSON หรือหัว `cf-ray` (เดิมหายเมื่อคำตอบไม่ใช่ JSON)
   - internal → “ระบบประมวลผลคำขอนี้ไม่สำเร็จ กรุณาลองใหม่หรือแจ้งรหัสอ้างอิง”

   - ปุ่ม **“คัดลอกรายงานปัญหา”** ใน “ดูรายละเอียด” (เริ่มแบบยุบ) — ถ้าคัดลอกอัตโนมัติไม่ได้ จะแสดงข้อความที่เลือกไว้ให้กด Ctrl+C เอง · ไม่ส่งให้ใครอัตโนมัติ

## 4) วิธีคัดลอกและค้นด้วย ref

ผู้ใช้: แถบเตือน → “ดูรายละเอียด” → “คัดลอกรายงานปัญหา” → วางส่งผู้ดูแล (มีเวลาไทย หน้า รุ่น แหล่ง HTTP code stage ref)
ผู้ดูแล (สิทธิ์ Cloudflare เดิม · ไม่มี API ให้พนักงานทั่วไปอ่าน) — วิธีที่ตรวจแล้วในรอบนี้คือ D1 API แบบ parameterized:

```
POST https://api.cloudflare.com/client/v4/accounts/<account_id>/d1/database/a4422729-f2fd-4b8b-b5e1-40850469a89e/query
{ "sql": "SELECT datetime(at/1000,'unixepoch','+7 hours') AS bkk, ev, route, scope, part, stage, status, code, type, cause, msg, rev FROM diag_log WHERE ref = ? ORDER BY id",
  "params": ["<ref>"] }
```
หรือ Cloudflare Dashboard → D1 → ฐานของ mu-traffic-hub → Console (พิมพ์คำสั่งเดียวกันโดยใส่ ref แทน `?`)
ค้นช่วงเวลาได้: `WHERE at >= strftime('%s','2026-11-20 00:00','-7 hours')*1000` · ค้นย้อนหลังได้เท่าที่ยังอยู่ใน 1,000 รายการล่าสุด
