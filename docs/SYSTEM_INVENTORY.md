## 4. ข้อสังเกตที่ควรจัดการในระบบต้นทาง (รายงานเท่านั้น ไม่ได้แก้)

เรียงตามความเร่งด่วน

1. **API key ใน repo สาธารณะ** — `report-incident-AI-v1/config.js` บรรทัด 3 (`VISION_API_KEY`): ควรยกเลิก key เดิมแล้วออกใหม่แบบจำกัด referrer/API หรือย้ายการเรียก Vision ไปฝั่ง Apps Script
2. **รหัสผ่านในไฟล์สาธารณะ** — `trafficoppe/admin.html` (บรรทัด 404, 469, 481), `borrowform/borrow_list.html` (495), `borrow_dashboard.html` (340): เปลี่ยนรหัสทั้งหมด (ค่าเดิมอยู่ในประวัติ git แล้ว) และย้ายการตรวจไปฝั่งเซิร์ฟเวอร์
3. **API ที่ส่งข้อมูลบุคคลโดยไม่ล็อกอิน** — CCTV `getData` (มีเลขบัตรประชาชน), ยืม-คืน `getAllData` (มีลิงก์รูปบัตร), DashboardAI (รายละเอียดผู้บาดเจ็บ)
4. **Sheet ที่มีข้อมูลบุคคลแชร์แบบ “ทุกคนที่มีลิงก์”** — ฐานข้อมูลงานจราจร, แจ้งของหาย, CCTV Request System, ระบบยืมของ (ระบบ PDF 4 ตัวพึ่งการแชร์นี้อยู่ จึงต้องย้าย PDF ไปอ่านผ่าน Apps Script ก่อนปิดการแชร์)
5. **ข้อมูลทดสอบปนข้อมูลจริง** — แท็บ `จำนวนรถเข้า+หมวกนิรภัย` แถววันที่ 16–17 ก.ย. 2569 (11 แถว)
6. **บัญชีลิงก์ไม่ตรง** — แท็บ “ลิงค์ทั้งหมด” ระบุโครงการ Apps Script ของแบบประเมินส่วนกลางไม่ตรงกับซอร์ส
7. ข้อมูลเหตุการณ์ก่อน 1 ก.ค. 2569 อยู่ในไฟล์เดิม “Copy of รายงานเหตุการณ์ใหม่ล่าสุด (Responses)” ยังไม่ได้รวมกับฐานข้อมูลปัจจุบัน
