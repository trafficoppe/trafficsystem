## 1. หน้าแรกและกติกา “วันนี้”

- หน้าแรก: ตัวเลือก วันนี้ / เดือนนี้ / ปีนี้ / กำหนดช่วง → การ์ดเรื่องละ 1 ใบ (8 เรื่อง) → กราฟแนวโน้มรายเดือน + แผนที่ → คลิกเปิดหน้ารายละเอียดในระบบ · ไม่มีตาราง · ตารางและรายละเอียดอยู่ที่ “รายงานประจำเดือน” (10 หมวดตามระบบเดิม เลือกเดือนแล้วกรองทุกหมวดที่มีวันที่)
- “วันนี้” = วันที่ตามเวลา Asia/Bangkok ณ ตอนเปิดหน้า (ทดสอบ 23:59 และ 00:01 น. โดยตั้งเขตเวลาเครื่องเป็น America/New_York)
- แสดง **0 ของวันนี้** ได้เฉพาะเมื่อชุดข้อมูลรายวันมี `complete: true` (อ่านต้นทางครบทั้งแท็บสำเร็จ) **และ** วันที่ใน `checkedAt` (เวลาที่อ่านต้นทาง) คือวันนี้ → ป้าย “วันนี้ ณ HH:MM น.” + “รายการที่บันทึกแล้ว ณ เวลาตรวจ”
  - วันที่เปิดหน้าเลยวันที่อ่านต้นทาง → “ยังไม่มีข้อมูลวันนี้” + วันที่รายการล่าสุด
  - อ่านไม่ครบ / ไม่มี `checkedAt` → “ยังยืนยันข้อมูลวันนี้ไม่ได้” และกราฟ 14 วันจบที่รายการล่าสุด (ไม่เติมศูนย์)
  - เวลา build และเวลาเปิดหน้า **ไม่ถูกใช้** เป็นหลักฐานความครอบคลุม
- ข้อจำกัดที่ต้องรู้: ไฟล์สถิติเป็น snapshot — หลังวันที่ 15 พ.ย. การ์ดเหตุการณ์/Lost & Found จะขึ้น “ยังไม่มีข้อมูลวันนี้” จนกว่าจะอ่านต้นทางใหม่ (ถูกต้องตามกติกา แต่แปลว่าหน้าแรกยังไม่ “สด”)
- ข้อมูลรายเดือนเท่านั้น (Anywheel, รถราง, CCTV, รปภ.) → แสดงเดือนล่าสุดพร้อมชื่อเดือน ไม่หารเป็นรายวัน · ทะเบียน (ลานจอด/ยานพาหนะ) → ยอดล่าสุด + วันที่ของทะเบียน
- ช่วงของการ์ดบน (ปุ่มวันนี้ ฯลฯ) แยกจากช่วงของกราฟแนวโน้ม และแต่ละหน้าจำช่วงของตัวเอง (หน้าแรก / รายงานประจำเดือน / หน้ารายละเอียด)

## 3. ผลทดสอบ — แยก 4 กลุ่ม

**3.1 โค้ด/การใช้งานภายในที่ทดสอบได้จริง (Chrome headless, ไม่พึ่งบริการภายนอก)**
- กติกา “วันนี้” ทุกกรณี (15 พ.ย. / 10 พ.ย. / 20 พ.ย. / 23:59 / 00:01 / อ่านไม่ครบ), ปุ่มช่วง, การจำช่วงแยกหน้า, ปุ่มย้อนกลับ, ลิงก์ตรง
- หน้าแรกไม่มีตาราง 8 การ์ด, รายงานประจำเดือน 10 หมวดและตัวเลขตามเดือน, Tooltip, ทุกเมนูเปิดได้ ไม่มีหน้าค้าง, เดสก์ท็อป 1440×900 และมือถือ 390×844 ไม่ล้นจอ, ปุ่มผู้ช่วย AI บนมือถือหลบเมื่อเลื่อนลง
- แบบฟอร์ม: ตรวจข้อมูล/เติมค่าอัตโนมัติ/ไม่แสดงว่าบันทึกเมื่อไม่มีบริการ · หน้าภายในเมื่อไม่มีบริการ: ไม่เรียกช่องทางสาธารณะ · ไม่มี Console error จากโค้ดของระบบ
- บริการ: ตรรกะตรวจ JWT (ไม่มี token, header ปลอม, alg none/HS256, ลายเซ็นผิด, แก้ payload, iss/aud ผิด, หมดอายุ, ไม่มีสิทธิ์, ยังไม่ตั้งค่า), กรองคอลัมน์, CORS/Origin, จำกัดจำนวนคำถาม, ข้อเท็จจริงและตัวตรวจตัวเลข

## 5. วิธีตรวจบนเครื่อง Windows (ประมาณ 5 นาที)

1. แตกไฟล์ `preview_hub_v7_package.zip` ทั้งโฟลเดอร์
2. ดับเบิลคลิก `START_PREVIEW_WINDOWS.bat` → หน้าต่างดำแสดง `Preview ready: http://localhost:8765/dist/preview.html` และเบราว์เซอร์เปิดเอง (ถ้า Windows ถามเรื่อง SmartScreen ให้เลือก More info → Run anyway; สคริปต์ฟังเฉพาะเครื่องนี้) · ถ้ามี Python: `py tools\serve_preview.py`
3. ตรวจ: (ก) หน้าแรก — แผนที่มีถนน/อาคารจริง ไม่ใช่พื้นเทา (ข) เมนู ยานพาหนะทั้งหมด / อุปกรณ์ดับเพลิง / ข้อมูลการจอดรถ / แบบฟอร์มทั่วไป — มีรายการจริงและรูปจริง (ค) กด F12 → Console ไม่มีข้อความแดงจาก `preview.html`

5. ปิด: ปิดหน้าต่างดำ
