## วิธีเปิดดู

- **แนะนำ (เห็นแผนที่จริงและรายการจาก Sheet):** เปิดผ่าน local HTTP — Windows ดับเบิลคลิก `START_PREVIEW_WINDOWS.bat` → เบราว์เซอร์เปิด `http://localhost:8765/dist/preview.html` · macOS/Linux หรือเครื่องที่มี Python: `python3 tools/serve_preview.py` → `http://127.0.0.1:8765/dist/preview.html` (ฟังเฉพาะเครื่องนั้น ไม่ใช่การ Deploy)

- เปิดไฟล์ `dist/preview.html` ได้เลย (ไฟล์เดียว ฝัง CSS/JS/สถิติรวมไว้แล้ว) — ต้องต่ออินเทอร์เน็ตเฉพาะเพื่อโหลดฟอนต์และตรามหาวิทยาลัย
- หรือเปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์ (เช่น `python3 -m http.server`) — เปิดจาก `file://` ตรง ๆ ไม่ได้เพราะต้องอ่าน `data/*.json`
- เปลี่ยนหน้าด้วย `#hash` (ปุ่มย้อนกลับของเบราว์เซอร์ใช้ได้ ส่งลิงก์ตรงหน้าได้) เช่น `#dashboard`, `#report-guard`, `#roster`, `#guard-central`, `#settings`

## รายงานตรวจรับ รปภ. (`#report-guard`)

- เลือก รปภ.ส่วนกลาง / รปภ.ส่วนงาน และเดือน–ปี · KPI คะแนนรวม, N, ด้านสูงสุด/ต่ำสุด · กราฟคะแนนรายด้าน, แนวโน้มคะแนน, จำนวนผู้ตอบ (แยกกราฟ), คะแนนรายด้านรายเดือน
- สองแบบประเมินแสดงแยกกัน ไม่รวมคะแนน · ไม่มีชื่อผู้ประเมินหรือข้อความปลายเปิด
- ค่าปรับ รปภ.: จำนวนกรณีและยอดรายเดือนจากแท็บ `รายงานเหตุการณ์` (ประเภท “ปรับ รปภ.”) — อัตรา 1,000 บาท/กรณียัง**รอยืนยัน**

## หลักการข้อมูล

- หน้าเว็บอ่าน **เฉพาะสถิติรวม** จาก `data/stats.json` (หรือ Stats API) — ไม่อ่าน Google Sheet ดิบ
- ไม่มีชื่อ เบอร์โทร ทะเบียนรถ รายละเอียดผู้แจ้งเหตุ รูปภาพ รหัสผ่าน หรือ API key ในไฟล์ใด ๆ ของ branch นี้
- ตัวเลขทุกตัวระบุแหล่งข้อมูลและเวลาอัปเดตล่าสุด; ระบบที่ยังยืนยันไม่ได้แสดง “ยังเชื่อมต่อไม่ได้ / ไม่มีข้อมูลยืนยัน”
- วันที่ตีความตามเขตเวลา Asia/Bangkok

## ที่มาของตัวเลขใน `data/stats.json`

Sheet ใหม่ใน Drive ของผู้ดูแล: **“STAGING – สถิติรวมสำหรับหน้ารวมงานจราจร (คำนวณจาก Sheet จริงแบบอ่านอย่างเดียว) – สร้าง 14.11.69”**
ใช้สูตร `IMPORTRANGE` + `QUERY` อ่าน Sheet ต้นทาง แล้วคัดเฉพาะยอดรวมมาไว้ใน `tools/build_snapshot.py`
(สคริปต์มี assert ตรวจว่ายอดรายเดือนรวมกันเท่ายอดรวม) — ไม่มีการเขียนกลับไปยัง Sheet ต้นทาง

ความพึงพอใจ รปภ. และค่าปรับ: แท็บ `T_SAT` และ `T_FINE` ใน Sheet เดียวกัน (สคริปต์ build ตรวจผลรวมรายเดือนเทียบกับสูตรใน Sheet ด้วย assert)

ข้อยกเว้น: ตัวเลขลานจอดงานปริญญา อ่านตรงจากแท็บ `SUMMARY_2569` (150 แถว) เพราะ Sheet นั้นยังไม่อนุญาต `IMPORTRANGE`

## การอัปเดตข้อมูล

- **แบบไฟล์ (ตอนนี้):** เปิด Sheet STAGING → นำยอดรวมมาแก้ใน `tools/build_snapshot.py` → `python3 tools/build_snapshot.py && python3 tools/build_preview.py`
- **แบบสด (แนะนำเมื่ออนุมัติ):** Deploy `apps-script/HubStats.gs` เป็นโครงการใหม่ แล้วใส่ URL `/exec` ใน `config.js` → หน้าเว็บจะอ่านยอดรวมสดทุกครั้งที่เปิด (แคช 10 นาที)

## แผนที่อุบัติเหตุ

ใช้พิกัดจริงจากคอลัมน์ “พิกัด (Lat, Lng)” เฉพาะอุบัติเหตุจากยานพาหนะและอุบัติเหตุทั่วไป (37 จุด) แสดงเดือน ประเภท ชื่อสถานที่ — ไม่แสดงเวลา บุคคล หรือเหตุรับส่งผู้ป่วย
- ค่าเริ่มต้น: แผนผังตามพิกัดในหน้า + ปุ่ม “เปิดใน Google Maps” + กรอบ Google Maps ของจุดที่เลือก (ไม่ต้องใช้ key)
- ถ้าต้องการแผนที่ Google เต็มรูปแบบ: ใส่ Browser key ที่จำกัด referrer และจำกัดเฉพาะ Maps JavaScript API ใน `config.js` (โค้ดส่วนนี้ยังไม่ได้ทดสอบเพราะไม่มี key)
